Allow internet access?

Downloading a model pulls a file from Hugging Face over the internet. Your local model still runs fully offline once downloaded — this permission only covers fetching new model files.

This is emb3r

A language model that runs on this computer. Not on a server, not on someone else's hardware — here, on the machine in front of you.

That means no account, no API key, and no bill. It also means the model has to be downloaded once before it can answer anything.

Nothing leaves this machine

Once a model is downloaded, emb3r can answer with the network off entirely. Your conversations and any file you attach are read here and stay here.

There is an indicator in the top left that lights up only while something is genuinely being sent, and it names what is sending it. Settings → Privacy keeps a log of every connection, and an offline lock that refuses them all.

What should Ember call you?

Ember is told your name so it can address you properly. It is stored on this machine with everything else.

Optional — leave it blank and Ember simply will not use a name. You can change it later in Settings → Account.

Privacy

While this is on, emb3r refuses every connection it would otherwise make: model downloads, update checks, Gemini web access and Spotify all stop working until you turn it off. It is enforced in the place the connections are actually made, so it holds even for code inside the app's dependencies — not just hidden in this interface.

It does not firewall the rest of your computer. Your operating system and other apps are unaffected.

Student mode

Ember is told, before every reply, that it is talking to a school student: no sexual content, no graphic violence, no profanity, and nothing about weapons, drugs or self-harm. If a student brings up hurting themselves, Ember says plainly to talk to a teacher or another trusted adult instead of trying to counsel them.

A small number of blunt, explicitly harmful questions are answered with a fixed safe reply and never reach the model at all — or the web, if web access is on.

Be clear about what this is. It steers a language model; it does not police it. A determined student can still phrase something to get around it, and it is not a substitute for supervision or for your school's network filtering. It reduces accidental exposure — treat it as that, not as a guarantee.

While it is on, the Personality page is read-only, because Ember's instructions are the thing student mode changes.

Without a PIN, student mode is a setting anyone can switch off. Set one and turning it off asks for it first. Turning it on never needs a PIN.

Keep the PIN somewhere you can find it. There is no recovery — if it is lost, the only way back is to delete emb3r's config file.

Personality

Student mode is on, so this is read-only. Turn it off under Student mode to edit Ember's personality.

Spotify

Web access

Get a key from aistudio.google.com/apikey. New keys start with AQ.; older ones start with AIza and Google stops accepting those in September 2026. Both work here. Use Test key after saving — it makes one real request and tells you exactly what Google said, rather than leaving you to find out when a reply quietly comes from the local model instead.

Models

Add your own

Paste a Hugging Face or GitHub link and pick which version to download, or point emb3r at a .gguf file you already have. Only GGUF models work here — that is the format the local engine reads.

Downloads are only accepted from huggingface.co and github.com, and what arrives is checked for the GGUF header before it is added. A model you point at on disk is used where it sits — emb3r does not copy it, and removing it from this list never deletes your file.
